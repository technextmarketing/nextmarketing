Client Overview

MetalForm Precision is a Shah Alam-based precision engineering company producing custom metal components for the aerospace, automotive, and electronics manufacturing sectors. With 14 active key accounts and a steady stream of new RFQ enquiries, the company's sales tracking had grown entirely around a combination of email threads, a shared WhatsApp group called 'Leads', and an Excel file that only one admin could update.

The operations manager had estimated they were losing 2–3 qualified enquiries per month simply because leads sat unanswered in the WhatsApp group for 4–6 hours — long enough for a competitor to respond first. There was no lead assignment system, no qualification criteria, and no visibility into which enquiries had been quoted and which were still pending.

TechNext Asia configured Odoo CRM from scratch: custom pipeline stages aligned to MetalForm's specific quoting process, a lead auto-assignment rule based on enquiry source, an imported lead score model for prioritising hot RFQs, and a migration of all 67 existing leads and active accounts from the Excel file — all live within 12 working days.

The Challenge
  • All leads managed in a WhatsApp group — no assignment, no tracking, no visibility for management
  • Average lead response time of 4–6 hours — RFQ enquiries routinely beaten by faster-responding competitors
  • No qualification criteria — all enquiries were treated equally regardless of order value or urgency signals
  • 67 existing active leads and accounts sitting in an Excel file with inconsistent field naming and duplicate entries
  • No email alias for inbound enquiries — all RFQs arrived in a personal Gmail inbox rather than a shared sales account
  • Zero integration between inbound website enquiries and the sales team — enquiries via web form required manual monitoring
  • No reporting capability — management had no visibility into monthly RFQ volume, win rate, or sales cycle length
Our 60-Day CRM Implementation
Week 1

Odoo Configuration & Stage Setup

  • Logged into Odoo → CRM module → Configuration → Stages: created 7 custom stages: New RFQ → Contacted → Qualified → Quoted → Negotiation → Won / Lost
  • Set up sales email alias: rfq@metalform.my → auto-creates Odoo CRM lead for every inbound email — eliminates personal Gmail dependency
  • Created lead auto-assignment: RFQs from website form → Rep A, email alias → Rep B, trade show contacts → Rep C
  • Configured required fields: company, contact name, email, enquiry type (new part / repeat order / prototype) — mandatory before stage advance
Week 2

Lead Scoring & Data Migration

  • Built lead scoring model with Claude AI: order value estimate, new vs repeat customer, urgency signal (deadline stated), industry (aerospace highest priority)
  • Added custom field 'Lead Score' to Odoo opportunity card — scoring guide published in Google Sheets for team reference
  • Cleaned Excel file: deduplicated 67 records, standardised field names, removed 12 inactive contacts
  • Imported all 55 clean leads into Odoo CRM → verified stage assignment, rep assignment, and expected close date for each record
Week 3–8

Testing, Training & Optimisation

  • Full flow test: submitted web enquiry → confirmed Odoo lead created → auto-assigned to correct rep → confirmation email fired in 8 minutes
  • Trained all 3 sales reps and admin: 2-hour hands-on Odoo session with live walkthroughs of each pipeline stage
  • Built weekly reporting view in Odoo: RFQ volume, stage distribution, win rate, and average days in each stage
  • Week 8: all new leads entering CRM within 2 minutes of enquiry — response time averaged 38 minutes vs previous 4–6 hours
